Upload Security Policy
  • All file types are supported — photos (JPG, PNG, HEIC, WEBP), PDF, Word, Excel, and archive files.
  • Maximum upload size is 5MB per file.
  • Filenames are sanitized and stored under secure server storage before metadata is saved.
  • Only executable/script file types (.exe, .bat, .php, .js, and similar) are blocked for security.
